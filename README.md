# VK Video Saver

Мини-сайт: вставляешь ссылку на видео VK, получаешь список качеств, скачиваешь.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Открой http://localhost:5000

## Продакшен

```bash
gunicorn -w 4 -k gthread --threads 8 --timeout 120 -b 0.0.0.0:8000 app:app
```

Поставь за nginx и включи HTTPS. Для nginx отключи буферизацию на `/api/download`:

```
location /api/download { proxy_buffering off; proxy_pass http://127.0.0.1:8000; }
```

## Как работает

- `POST /api/info`: yt-dlp достаёт метаданные и прямые mp4-ссылки.
- `GET /api/download`: сервер стримит файл с VK клиенту, ничего не храниться на диске.
- Принимаются только домены VK (vk.com, vkvideo.ru и т.д.), чтобы сервис нельзя было использовать как открытый прокси.

## Ограничения

- Работают публичные видео. Приватные и только для друзей без авторизации не отдадутся.
- Берутся только прямые файлы (mp4). Если у видео только HLS/DASH, качества не будет в списке.
- Размер файла берётся у VK через HEAD-запрос; если он недоступен, показывается оценка по битрейту (со знаком ≈).
- yt-dlp часто обновляется под изменения VK: если сломалось, делай `pip install -U yt-dlp`.
- Для публичного сервиса добавь rate limit (например, Flask-Limiter) и учитывай нагрузку на трафик.
- Скачивай только то, на что у тебя есть права.
